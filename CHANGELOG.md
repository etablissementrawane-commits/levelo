# Changelog

## QuestLog MVP

- Phase 1: Added app theme colors, animated gradient background, and game balance configuration.
- Phase 2: Added reusable glass surfaces and floating five-tab navigation.
- Phase 3: Added Hive persistence, Riverpod app state, and pure game reward/damage calculations.
- Phase 4: Added habits, dailies, to-dos, rewards, task editing, onboarding, profile, and settings screens.
- Phase 5: Added haptics and level-up/faint feedback dialogs.
- Phase 6: Added app-resume rollover handling for missed dailies.
- Phase 7: Added avatar/name customization and hard-mode/theme settings.
- Phase 8: Added accessibility labels, empty states, README, and tests.
